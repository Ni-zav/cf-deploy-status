## Bug found by dogfooding

The live Worker reconciliation test exposed an incorrect assumption about the Cloudflare Workers deployment-history API response shape.

The parser expected:

```text
result: Deployment[]
```

The live API returns:

```text
result: {
  deployments: Deployment[]
}
```

The parser and its reconciliation tests were corrected on public `main` in:

- `ceea2d73df3f04c53e97fa196f8962eeee44de41` — `fix: parse Workers deployment history response`

The CI run for that commit completed successfully.

This is exactly why the v1 release process requires real account-level dogfooding in addition to mocked integration tests.
